# Accessibility

What the Action itself shows:

- **The job summary**, a Markdown table GitHub renders with its column headings.
- **Warnings**, plain-text workflow annotations; the job summary repeats them.
- **Outputs**, plain strings.
- **The [README](README.md)**, Markdown read on GitHub or in any editor.

No colour or symbol alone carries a meaning: what each says is in its words.

Everything else, the plugin's output included, and how to report a barrier, is in yoriwake's
[accessibility statement](https://github.com/zeuspizza/yoriwake/blob/main/ACCESSIBILITY.md).
